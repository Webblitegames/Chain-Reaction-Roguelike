# Chain-Reaction Roguelike

Mobile-first prototype for a physics-based roguelike about constructing increasingly absurd Rube Goldberg machines, then pressing **GO** and watching the chain reaction resolve.

## V0.1
- Touch placement
- Ball, domino, ramp, spring, target
- Matter.js physics
- GO / Reset / Undo / Clear
- Chain-reaction score and combo multiplier
- Persistent local high score
- Procedural prototype sound cues

Open `index.html` in a browser.
